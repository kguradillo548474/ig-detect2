# XGBoost-Based Detection of Fake Instagram Accounts

Machine learning pipeline and Streamlit dashboard for detecting fake Instagram profiles with XGBoost, built on the
Instagram Fake and Genuine Accounts dataset (5,000 labeled profiles, 4,934 after duplicate removal).
Group 17 · CST9 · University of Mindanao.

**Test-set results (987 profiles):** accuracy 98.99% · precision 99.59% · recall 98.37% · F1 98.98% · ROC-AUC 0.9995

## Project structure
```
fake-ig-detector/
├── data/Instagram.csv          <- raw dataset
├── models/xgb_model.json       <- trained model (generated by train.py)
├── outputs/                    <- metrics.json, confusion_matrix.png, roc_pr_curves.png,
│                                  feature_importance.png, score_distribution.png, eda_*.png
├── src/
│   ├── config.py               <- paths, feature names, hyperparameters
│   ├── utils.py                <- data loading, cleaning, split, feature engineering
│   ├── eda.py                  <- exploratory data analysis plots
│   ├── train.py                <- training and evaluation
│   ├── predict.py              <- inference (CLI + Python API)
│   ├── tune.py                 <- optional Optuna hyperparameter search
│   └── app.py                  <- Streamlit dashboard
├── .streamlit/config.toml      <- dark theme
└── requirements.txt
```

## Usage
```bash
pip install -r requirements.txt
python src/eda.py                 # EDA plots
python src/train.py               # train + evaluate (add --grid to re-run the full grid search)
python src/predict.py --username user83920174 --followers 12 --follows 900 --nopic
streamlit run src/app.py          # dashboard
```
No feature scaling is used because XGBoost is tree-based and insensitive to feature scale.

## Deploy (Streamlit Community Cloud)
Push this folder to GitHub -> https://share.streamlit.io -> New app -> main file path `src/app.py`.
